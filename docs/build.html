§ assembly / 7 steps · about 30 minutes

Assembly guide.

From a bag of parts to a critter that reacts to Claude Code. Plan about half an hour, plus the time to build the image if you build it yourself.

early daysThe image has not been tested on real hardware yet. If something below does not match what you see, the troubleshooting notes may help.

You need

  • Claude Code, set up and working on your computer. The gotchi shows what Claude Code is doing, so without it there is nothing to show. Claude Code needs a Claude subscription or an Anthropic API account.
  • A Mac, Linux or Windows computer with Python 3.9 or newer. macOS ships it with the command line tools (xcode-select --install), most Linux systems have it already, and on Windows you get it from python.org. Windows also needs Git for Windows, which Claude Code recommends anyway: hooks and the status line run in its Git Bash, and that is where you paste the commands below.
  • The parts from the shopping list
  • Raspberry Pi Imager to flash the card

  1. Put the display on the Pi

    Unplug everything first. Hold the Pi with the header pins facing up and press the e-Paper HAT onto the 40-pin header so the HAT lies right on top of the Pi and its outline matches the board. Push down evenly on both ends of the connector until it sits flush. Do not press on the glass of the display.

    The display talks to the Pi over SPI. If you wire it by hand instead of using the HAT connector, these are the pins the driver uses (BCM numbering): RST 17, DC 25, CS 8 (CE0), BUSY 24, PWR 18, plus MOSI 10, SCLK 11, 3.3 V and GND.

  2. Optional: add the battery

    Skip this step if the gotchi stays on your desk on its cable. With a PiSugar 3 it runs on its own. Make sure the battery cable is plugged into the PiSugar board, then hold the PiSugar under the Pi, battery side down, so the four screw holes line up. Its pogo pins at one end must sit under the first pins of the 40-pin header, where they press against the solder pads from below and carry power and I2C. Screw the boards together with the spacers and screws that come with the PiSugar. No soldering, and the display still goes on top as before.

    Charge it through the USB-C port on the PiSugar and switch it on with its power button; how long to press is in the PiSugar manual. The gotchi finds the PiSugar by itself: a small battery appears in the header, with a lightning bolt while it is charging. At 15 % the critter asks to be plugged in, and at 5 % it shuts down cleanly so the card is not cut off mid-write. Over the cable it still talks to your computer as before.

  3. Get the image

    Download the ready-made image from the download page: claudegotchi-zero2w.img.xz for the Pi Zero 2 W or claudegotchi-zerow.img.xz for the Pi Zero W.

    Developers with the source code can also build it themselves on a Debian or Ubuntu machine. The first build downloads Buildroot and all sources and takes about an hour.

    $ sudo apt-get install build-essential bc cpio rsync unzip file wget
$ make zero2w      # or: make zerow
# result: output/zero2w/images/claudegotchi-zero2w.img.xz

  4. Flash the card

    In Raspberry Pi Imager, pick Choose OS → Use custom and select the .img.xz file. Choose the microSD card and write. Skip Imager's OS customisation: the gotchi has its own settings file.

  5. Optional: Wi-Fi and settings

    After flashing, the card shows up on your computer as a drive called GOTCHI. It holds claudegotchi.toml. Without Wi-Fi the gotchi works over the USB cable only, which is all you need on your desk. To use it over Wi-Fi or with the cloud relay, fill in the [wifi] section:

    [wifi]
ssid = "MyNetwork"
psk = "my-wifi-password"
country = "DE"

    You can change all of this later in the browser, see settings.

  6. Plug it in

    Put the card into the Pi. Connect the cable to the micro-USB port labelled USB, not the one labelled PWR. On the USB port the gotchi gets power and shows up on your computer as a small network adapter. Your computer gets an address automatically, and the gotchi is reachable at 192.168.77.1.

    After booting, the critter appears on the display. On a Mac, if macOS asks whether to allow the new accessory to connect, allow it. Windows sets it up as a USB network adapter (RNDIS) on its own; Linux usually brings it up through NetworkManager.

  7. Connect Claude Code

    Now teach Claude Code to talk to the gotchi. It comes as a Claude Code plugin. In Claude Code, add the Claudegotchi marketplace and install the plugin:

    $ /plugin marketplace add https://claudegotchi.lottes.dev/marketplace.json
$ /plugin install claudegotchi@claudegotchi

    The plugin adds hooks that report each event to the gotchi. It asks for an address, a token and a relay; leave all three empty for now. You can change them later in /plugin.

    Plugins cannot set the status line, and the status line is where the gotchi learns how much of your 5-hour and 7-day budget is left. To add it, run this in a terminal:

    $ curl -fsSL https://claudegotchi.lottes.dev/install.sh | sh -s -- --statusline-only

    It keeps your existing status line and still shows it. You can read the script before you run it.

    No plugin? curl -fsSL https://claudegotchi.lottes.dev/install.sh | sh installs hooks and status line in one go, straight into ~/.claude/settings.json. Use either the plugin or this, not both, or every event reaches the gotchi twice.

    On Windows, run the terminal commands in Git Bash. Then check that the gotchi answers. The test walks the critter through its moods over about a minute:

    $ sh ~/.claude/claudegotchi/claudegotchi.sh test

    By default the client tries the USB cable first and then claudegotchi.local on your Wi-Fi. You can also watch the display live in a browser at http://192.168.77.1:8765/.

  8. Start Claude Code

    Close running Claude Code sessions and open a new one, so it picks up the plugin. The critter says hello, gets busy while Claude works, raises its arms when Claude needs your permission and lets you know when the reply is done.
