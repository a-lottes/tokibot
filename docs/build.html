Assembly guide

From a bag of parts to a critter that reacts to Claude Code. Plan about half an hour, plus the time to build the image if you build it yourself.

Early days. The image has not been tested on real hardware yet. If something below does not match what you see, the troubleshooting notes may help.

You need

  • The parts from the shopping list
  • A Mac or Linux computer with Python 3.9 or newer and Claude Code
  • Raspberry Pi Imager to flash the card

  1. Put the display on the Pi

    Unplug everything first. Hold the Pi with the header pins facing up and press the e-Paper HAT onto the 40-pin header so the HAT lies right on top of the Pi and its outline matches the board. Push down evenly on both ends of the connector until it sits flush. Do not press on the glass of the display.

    The display talks to the Pi over SPI. If you wire it by hand instead of using the HAT connector, these are the pins the driver uses (BCM numbering): RST 17, DC 25, CS 8 (CE0), BUSY 24, PWR 18, plus MOSI 10, SCLK 11, 3.3 V and GND.

  2. Get the image

    Once a version is tagged, every GitHub release carries ready images: claudegotchi-zero2w.img.xz for the Pi Zero 2 W and claudegotchi-zerow.img.xz for the Pi Zero W.

    You can also build it yourself on a Debian or Ubuntu machine. The first build downloads Buildroot and all sources and takes about an hour.

    sudo apt-get install build-essential bc cpio rsync unzip file wget
make zero2w      # or: make zerow
# result: output/zero2w/images/claudegotchi-zero2w.img.xz

  3. Flash the card

    In Raspberry Pi Imager, pick Choose OS → Use custom and select the .img.xz file. Choose the microSD card and write. Skip Imager's OS customisation: the gotchi has its own settings file.

  4. Optional: Wi-Fi and settings

    After flashing, the card shows up on your computer as a drive called CLAUDEGOTCHI. It holds claudegotchi.toml. Without Wi-Fi the gotchi works over the USB cable only, which is all you need on your desk. To use it over Wi-Fi or with the cloud relay, fill in the [wifi] section:

    [wifi]
ssid = "MyNetwork"
psk = "my-wifi-password"
country = "DE"

    You can change all of this later in the browser, see settings.

  5. Plug it in

    Put the card into the Pi. Connect the cable to the micro-USB port labelled USB, not the one labelled PWR. On the USB port the gotchi gets power and shows up on your computer as a small network adapter. Your computer gets an address automatically, and the gotchi is reachable at 192.168.77.1.

    After booting, the critter appears on the display. On a Mac, if macOS asks whether to allow the new accessory to connect, allow it.

  6. Install the client

    Get the Claudegotchi repository onto your computer and run the installer. It adds hooks and a status line to ~/.claude/settings.json, makes a backup first, and keeps your existing hooks and status line.

    python3 client/install_mac.py
python3 ~/.claude/claudegotchi/claudegotchi_client.py test

    The test walks the critter through its moods over about a minute. By default the client tries the USB cable first and then claudegotchi.local on your Wi-Fi.

  7. Start Claude Code

    Open a new Claude Code session. The critter says hello, gets busy while Claude works, raises its arms when Claude needs your permission and lets you know when the reply is done.

Next steps

  • Upside down? Set rotate = 180 on the settings page.
  • Using Claude Code in the cloud? Set up the relay.
