# Security

Please don't report security problems in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/a-lottes/tokibot/security/advisories/new)
or write to andreas@lottes.dev.

Interesting areas are the gotchi's HTTP API and settings page, pairing and the
signatures between gotchis (friends, highscore cards), the cloud relay and the
install script. Please describe how to reproduce the problem and which version you
tested. You'll get an answer within a week; fixes go into the next release, and the
changelog credits you unless you'd rather not.

Only the latest release is supported.
