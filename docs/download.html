§ 01 / which file

Which file do I need?

  • tokibot-zero2w.img.xz: the image for the Raspberry Pi Zero 2 W (the default board).
  • tokibot-zerow.img.xz: the image for the first Raspberry Pi Zero W.
  • marketplace.json and tokibot.zip: the Claude Code plugin for your computer, which connects Claude Code to the gotchi. Add it with /plugin marketplace add https://tokibot.lottes.dev/marketplace.json, see step 7.
  • install.sh: adds the status line, or installs the client without the plugin.
  • tokibot-app.tar.gz: only the app. Upload it on the gotchi's settings page to update without reflashing.

Flash an image with Raspberry Pi Imager (Choose OS → Use custom). There is no need to unpack the .xz file first. The assembly guide walks through the rest.

§ 02 / verify

Check the download.

Compare the SHA-256 checksum with the one in the table:

$ shasum -a 256 tokibot-zero2w.img.xz   # macOS
$ sha256sum tokibot-zero2w.img.xz       # Linux
