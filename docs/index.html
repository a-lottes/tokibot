A pixel critter for your Claude Code sessions

Claudegotchi is a tiny e-ink gadget on your desk. Its mood shows what Claude Code is up to: working, waiting for you, asking for permission, done, or stuck at a rate limit.

What you need Build one

How it works

Claude Code calls a small client through its hooks and status line. The client sends a few lines of metadata to the gotchi, over the USB cable or Wi-Fi. The gotchi folds every running session into one mood and draws it on the e-paper display.

Claude Code ── hooks + status line ──► claudegotchi_client.py ──HTTP──► Pi: claudegotchi ──► e-paper
                                          (USB cable or Wi-Fi)

Knows your sessions

Several sessions or worktrees at once? The one that needs you most wins. The footer counts sessions that are working, waiting and done, plus your 5-hour and 7-day budget.

Grows with your work

Finished replies, tasks and tool calls earn experience. The critter levels up, keeps a daily streak, sums up your day in the evening and gets hungry when you leave it alone.

Its own tiny OS

A slim Buildroot image with a read-only root filesystem. No Debian, no Wi-Fi hacking tools, no SSH. Pulling the plug does not hurt the card.

Works with the cloud

Claude Code in the cloud cannot see your desk. An optional ntfy relay carries the events to the gotchi over any Wi-Fi, even your phone's hotspot.

Private by design

Only metadata leaves your computer: event, session ID, folder name, tool name and limit percentages. Prompts, code and replies never do.

Set up in the browser

Wi-Fi, time zone, rotation and token live on a small settings page on the gotchi. App updates install from there too, no reflashing needed.

Every mood

Twelve moods, each with its own face and a short line in the speech bubble.

Status

Version 0.2.0. The app runs in the simulator and the Buildroot configs are checked against Buildroot 2026.02.3. A full image build and a test on real hardware are still open, so expect rough edges if you build one now.
