§ 01 / which file

Which file do I need?

  • tokibot-zero2w.img.xz: the image for the Raspberry Pi Zero 2 W (the default board).
  • tokibot-zerow.img.xz: the image for the first Raspberry Pi Zero W.
  • marketplace.json and tokibot.zip: the Claude Code plugin for your computer, which connects Claude Code to the gotchi (other coding agents get their hooks from the install script). Add it with /plugin marketplace add https://tokibot.lottes.dev/marketplace.json, see step 7.
  • install.sh: adds the status line, or installs the client without the plugin.
  • tokibot-app.tar.gz: only the app. Upload it on the gotchi's settings page to update without reflashing.

Flash an image with Raspberry Pi Imager, best through the Tokibot list (see below): then Imager asks for your Wi-Fi. Choose OS → Use custom works too, without that step. There is no need to unpack the .xz file first. The assembly guide walks through the rest.

§ 02 / verify

Check the download.

Compare the SHA-256 checksum with the one in the table:

$ shasum -a 256 tokibot-zero2w.img.xz   # macOS
$ sha256sum tokibot-zero2w.img.xz       # Linux
§ 03 / raspberry pi imager

Wi-Fi straight from Imager.

Raspberry Pi Imager only offers its OS customisation for images from a list that says how to customise them. Tokibot has such a list. Open it in Imager in one of two ways:

  • Download tokibot.rpi-imager-manifest and double-click it. Imager opens with the Tokibot images.
  • Or in Imager: App Options → Content Repository → Edit → Use custom URL, enter https://tokibot.lottes.dev/downloads/imager.json and Apply & Restart.

Pick your board and the Tokibot image, then fill in Wi-Fi (name, password, country) and the time zone in the customisation step. On first boot the gotchi moves them into tokibot.toml and deletes Imager's files. Skip the other steps: the hostname, user account, SSH and Raspberry Pi Connect are not used, and the gotchi keeps its own name tokibot-xxxx. To get Imager's usual list back, choose Use default under Content Repository.

§ 04 / update a card

New image, same critter.

Already have a gotchi? Put its card into your computer and run the card updater (macOS and Linux). A small menu finds the card, lets you pick the version and asks before it writes anything. It backs up the settings in tokibot.toml (Wi-Fi, token), the progress partition (XP, level, friends, keys) and the start of the card into ~/tokibot-backup-…, writes the image and puts progress and settings back, checked byte for byte.

$ curl -fsSL https://tokibot.lottes.dev/update-card.sh | sh

It asks for your password because writing a card needs sudo, and it needs python3 (on macOS: xcode-select --install). You can read the script first. On Windows, flash with Imager and copy tokibot.toml back by hand. For a new app version alone you do not need to flash at all: upload tokibot-app.tar.gz on the gotchi's settings page.
